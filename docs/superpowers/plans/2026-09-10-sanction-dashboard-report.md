# 제재공시 카드에서 심층 보고서 열기

사용자 변경 요청: 날짜별 기존 대시보드와 공시 카드를 유지한다. Report의 별도
하위 메뉴 대신 공시 카드의 AI 심층 보고서에서 요약 브리핑·당행 소관부서·소관업무·점검 포인트를 읽는다.
운영 대상은 사용자가 확인한 `https://regulation-news-reg-fiu7.vercel.app/`이다.

1. 기존 ReportModal 진입점에서 제재/경영유의 기관만 새 제재 보고서 모달로 분기한다.
   보도자료·규제 보고서 생성 동작은 그대로 유지한다.
2. 게시 API에 기사 UUID 필터를 추가한다. 목록 첫 페이지를 클라이언트에서 찾지 않고
   해당 기사만 서버에서 조회해 오래된 공시도 정확하게 연결한다.
3. 제재 모달에는 건별 요약, 부서, 업무, 점검·증빙, 공개 근거 페이지, 원문, Excel을 표시한다.
   미게시·비활성·조회 실패·로그인 만료를 구분한다. 공개된 기존 요약이 있으면 별도로 표시한다.
4. 카드 클릭이 AI 생성 또는 내부 문서 조회를 일으키지 않는다. 게시 결과만 일반 사용자에게 반환한다.
5. 새 Report 하위 메뉴를 제거하고 관리자 화면의 대시보드 복귀 링크를 맞춘다.
   이전 직접 URL은 호환성을 위해 유지하되 주 진입점으로 사용하지 않는다.
6. API 기사 필터·모달 분기·늦은 응답·기존 보고서 회귀를 검증하고 별도 검토한다.

검증: 웹 전체 125개 테스트 및 production build 통과. 독립 검토에서 차단 문제 없음.
이번 UI 변경은 아직 커밋·배포하지 않았다. 운영 DB·관리자·worker 설정도 확인이 필요하다.
