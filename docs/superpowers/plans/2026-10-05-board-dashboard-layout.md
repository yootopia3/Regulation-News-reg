# 게시판 대시보드 레이아웃 통합

사용자 합의: 기존 사이드바를 유지하고 오른쪽 콘텐츠 영역에 게시판 목록/상세/작성/수정을 표시한다.
PC는 정돈된 목록 행, 모바일은 카드 목록. 기존 게시글 URL과 아침 리포트 링크를 유지한다.

1. DashboardFrame으로 기존 대시보드의 사이드바/콘텐츠 스크롤 영역을 공유한다.
2. BoardShell에 같은 Sidebar/Header를 사용하고 게시판 활성 상태를 표시한다.
3. 게시판에서 보도자료/규제개정/제재 공시 선택 시 검증된 category/agency URL로 이동한다.
   루트 페이지가 초기 선택을 읽고 해당 기관/분류를 보여주게 한다. 대시보드 내 기존 필터 동작은 유지한다.
4. BoardList를 PC 행/모바일 카드로 정리한다. 인증/API/DB 구조는 변경하지 않는다.
5. 공통 메뉴 및 모바일 열기/닫기, 분류 복귀, 게시판 모든 경로의 콘텐츠 표시를 테스트한다.
6. 별도 context 리뷰 후 타입·린트·관련/회귀 테스트를 완료한다.

시작 상태: ab888d9, 사용자 보고로 PR #3 main 병합 완료. Cloud GitHub 인증 오류로 최신 원격 fetch 불가.
변경은 별도 브랜치에 보존하고 원격 반영은 인증 복구 후 일반 push/PR로 수행한다.
