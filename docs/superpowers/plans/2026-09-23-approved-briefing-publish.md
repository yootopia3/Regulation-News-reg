# 승인된 국민은행 브리핑 웹 반영

사용자가 승인한 로컬 보고서를 기존 AI 심층 보고서 경로로 게시한다.
새 API 호출이나 DB 스키마 변경 없이 기존 검토 저장·게시 절차를 사용한다.

1. 공개 보고서 DTO를 읽는 화면을 요약 / 소관부서·업무 / 점검 질문·자료 예시의 세 구역으로 구성한다.
2. 업무 추정 표시를 유지하고, 자동 게시 결과의 담당자 확인 표시는 보존한다.
3. 국민은행 요약과 점검 질문 3개를 관리자 검토본으로 저장한 뒤 기존 게시 검증을 통과시켜 게시한다. 외환사업부는 포함하지 않는다.
4. 모달 테스트 및 production build, 별도 코드 리뷰 후 이번 화면 변경만 배포한다. 이전 미커밋 분석기 변경은 포함하지 않는다.
5. 운영 카드에서 게시 내용과 변경된 화면을 확인한다.

검토: 별도 review lane에서 헤더 부제 대비 개선 의견을 받아 slate-300으로 수정했다.
