# Stage B 분석 엔진

합의된 제재 점검 설계의 Stage B 중 분석·검색·근거 검증을 구현한다.
웹 실행과 운영 키가 없어도 합성 입력과 모의 Responses 응답으로 검증한다.

1. 페이지 번호가 있는 공개 제재 텍스트를 입력받아 지적사항을 구조화한다.
   빈/과대 입력, 근거 페이지 밖 인용, 거절·중단 응답은 실패로 처리한다.
2. 활성·검토 완료된 내부 조문에서 한국어 부분어 일치로 후보를 검색한다.
   같은 문서의 교차 참조를 포함하며 후보·본문 길이를 제한한다.
   조문 잘림/참조 누락 시 자동 결과 대신 검토 필요 오류를 반환한다.
3. 공개 지적사항 추출과 내부 부서 매칭은 분리한다. 후자에는 선택 조문만 전송한다.
   API는 고정 OpenAI Responses endpoint, store=false, 도구·대화 저장·fallback 없음.
   기능 플래그/정책 확인/모델/키가 없으면 요청하지 않는다.
4. 응답 스키마와 지적사항 ID·근거 조문 ID·인용문을 검사한다.
   부서명은 AI가 만든 문자열 대신 검토된 조문의 부서명으로 해석한다.
   모든 결과는 관리자 검토용이며 게시 가능한 DTO로 간주하지 않는다.
5. 문서 버전·입력·모델·프롬프트를 반영한 fingerprint를 생성한다.
6. 개인정보가 없는 합성 테스트, 기존 Python 회귀검증, 별도 코드 검토를 수행한다.

이번 단위는 네트워크 PDF 다운로드/격리 추출, DB 작업 큐·저장,
관리자 실행/검토/게시 화면에 선행하는 라이브러리다. 웹에서 아직 호출하지 않는다.
실제 문서 업로드/AI 품질 평가·운영 연결을 완료했다고 보고하지 않는다.

검증: Python 전체 164개 테스트 통과. 별도 검토의 외부 법령 조문 오연결과
범위 참조 누락을 자동 중단 및 검토 요구로 수정하고 회귀 테스트를 추가했다.
